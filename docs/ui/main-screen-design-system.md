# Визуальный язык главного рабочего экрана

Живой источник правды для шапки и кнопок рабочего экрана. Сюда попадает только то, что уже утверждено, и временные значения первой итерации.

Временное значение помечено `provisional / требует утверждения`. Его нельзя считать окончательным стандартом. В следующей итерации сначала смотреть этот файл и повторять уже записанные числа, а не заводить соседние.

Шрифт проекта — Montserrat. Новой шкалы размеров на этой итерации нет.

## Уже есть в интерфейсе входа

Эти значения не выдуманы для шапки. Их повторяем.

- Фон страницы: `--color-page`, `#05070b`. Чистый `#000000` не использовать.
- Текст иконки: `--color-text`.
- Контур фокуса: цвет акцента `--color-accent`.
- Нижний радиус шапки: 24px, как у карточки входа.
- Кривая движения: `cubic-bezier(0.22, 1, 0.36, 1)`, как у карточки входа.
- Шаг отступов: 4px.

## Шапка

`provisional / требует утверждения`, кроме радиуса 24px и кривой выше.

- Высота пластины: 56px.
- Отступ сверху: 12px. Отступ слева и справа: 16px.
- Покой: пластина компактная, низ скруглён на 24px.
- Наведение: пластина опускается на 8px и растягивается по вертикали до 1.08 от своей высоты. Точка опоры — верхний край. Длительность 280ms.
- Наведение не двигает кнопку и не скачет высотой документа: меняется только рисунок пластины.
- На сенсорном экране без точного курсора пластина не выдвигается.

## Островок

`provisional / требует утверждения`.

Заготовка по центру шапки. Бока лежат ниже нижней линии пластины. Внутри пусто. Это не копия чужого островка, только похожий силуэт, который позже можно наполнить.

- Ширина: 168px. Высота: 32px.
- Радиус: 16px.
- Свес ниже пластины: 12px.
- При наведении шапки островок опускается вместе с пластиной на 8px.

## Кнопка Home

`provisional / требует утверждения`, кроме кривой движения.

Круглая выпуклая стеклянная поверхность. Тонкий контур. Внутри контурный домик той же толщиной. Слабая тень, умеренный блик сверху. Без сильного свечения.

- Размер кнопки: 40px.
- Иконка: 16px. Толщина линии: 1.5px.
- Наведение: масштаб 1.06, та же кривая, 280ms.
- Нажатие: поворот поверхности с иконкой от 0° до 180° и сразу до 360°, чтобы домик снова стоял прямо. В середине короткое увеличение до 1.06. Вся фраза 320ms.
- Если адрес уже `/home`, переход не делается.
- При `prefers-reduced-motion` поворот и выдвижение шапки выключены.

## Как добавлять следующую кнопку

Та же круглая поверхность 40px, тот же контур, та же тень и то же наведение. Новая иконка не заводит новый размер, пока это значение не заменят в этом файле.
